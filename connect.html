setup

Hook this site up to your Remix deploy.

The website can't see Remix's built-in simulated chain, because that lives inside the Remix tab. So you deploy to a chain the browser can reach (Sepolia, or a local node), then tell the site where the contract is.

the sequence
  1. Test the contract first (optional). In Remix, Deploy & Run → environment Remix VM → Deploy. Click the functions and watch them work or revert. Nothing here touches the website.
  2. Pick a chain the browser can reach. Easiest: MetaMask on Sepolia with free faucet ETH. Alternative: a local Ganache or Hardhat node, with that network added to MetaMask.
  3. Deploy for real. In Remix set environment to Injected Provider - MetaMask (it deploys to whatever network MetaMask is on). Hit Deploy and confirm. Your deploying wallet becomes the owner and a valid issuer.
  4. Copy the address. Remix → Deployed Contracts → copy icon next to the contract name.
  5. (Optional) Copy the ABI. Remix → Solidity Compiler tab → the ABI button at the bottom. The site already ships with a matching ABI, so only paste yours if you changed the contract.
  6. Fill in the form below, hit Test connection, then Save & use.
